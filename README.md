# מדינות העולם

אוסף של 150 כרטיסי מדינות בעברית, לילדים סביב גיל 9, לקריאה ולהדפסה. הנתונים מקומיים; דגלים, גופנים ושערי מטבע במסך משתמשים בשירותים חיצוניים.

פתחו את `index.html` בדפדפן, או הפעילו שרת מקומי:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

החיפוש פועל בעברית עם ניקוד או בלעדיו ובאנגלית. סינון היבשת והחיפוש קובעים אילו כרטיסים יודפסו. מספר העמודות וכיוון העמוד קובעים את פריסת ההדפסה; במסך טלפון מוצגת עמודה אחת. מקורות והערות תחזוקה נשמרים בקובצי הביקורת ואינם מוצגים בכרטיסים.

## מספרי המדינות והמפה

לכל מדינה הוצמד מספר קבוע 1–150, המופיע בכרטיס באתר ובחוברת. המספר נשאר זהה גם בעת חיפוש או סינון ומשמש כמפתח בין הכרטיס למפה.

- רשימה לקריאה: `output/COUNTRY_MAP_INDEX_HE.md`.
- נתונים למפה: `output/country-map-index.csv` ו־`output/country-map-index.json`.
- מקור המספור של המוצר: `data/country-map-index.js`.
- `npm run build:country-index` מרענן שמות ושדות בלי לשנות את המספרים. שינוי מכוון של הסדר דורש `node scripts/country-index.cjs --rebuild` ובדיקה מול המפה.

## חוברת A5 על נייר A4

פתחו את `booklet.html` לתצוגת A4 מוכנה לחוברת. בכל צד A4 יש שני עמודי A5 זה לצד זה, ובכל אחד ארבעה כרטיסים בגריד 2×2. כך מתקבלים שמונה כרטיסים בכל צד ועד 16 בדף דו־צדדי.

- `output/pdf/know-the-world-booklet-a4-print.pdf` כבר מסודר לדפוס: בחרו גודל אמיתי, דו־צדדי והיפוך בצד הקצר. אין להפעיל עליו שוב Booklet.
- החוברת כוללת 52 עמודי A5 על 13 דפי A4 פיזיים, ובהם עמוד פתיחה נפרד לכל אחת משש היבשות.
- איורי הוינטג׳ לכריכות ולששת פתיחי היבשות נמצאים ב־`assets/booklet-images/` ומשולבים בחוברת.
- פרומפטים עקביים לכריכה ולכל שש היבשות נמצאים ב־`assets/IMAGE_PROMPTS_HE.md`.
- סט מלא בסגנון כרזת מסע וינטג׳ית, כולל כריכה אחורית, נמצא ב־`assets/VINTAGE_IMAGE_PROMPTS_HE.md`.
- מחקר ההשראה וההחלטות החזותיות נמצא ב־`audit/DESIGN_INSPIRATION_HE.md`; מוקאפ ארבעת הכרטיסים נשמר ב־`design-inspiration.html`. שפת פנקס המסע הוחלה גם על המוצר עצמו.
- סדר ההטלה המלא לכל 13 הדפים מתועד ב־`audit/BOOKLET_PRINT_ORDER_HE.md`.

## אמינות הנתונים

- [דוח הביקורת](audit/REPORT.md) — ממצאים, מקורות ומגבלות.
- [מצב בדיקה לכל מדינה](audit/review-status.json) — אין סימון אוטומטי של מדינה שלמה כמאומתת.
- [שאלות פתוחות](audit/open-questions.json) — טענות שדורשות המשך מחקר.
- [תוצאות אימות המוצר](audit/VERIFICATION.md).

האוכלוסייה היא אומדן אמצע 2025 מסדרת World Bank SP.POP.TOTL, עם תאריך משיכה ומקור ברשומת הנתונים הפנימית. הכרטיס מציג מספר מעוגל בלבד. נתוני 2024 נשמרו להשוואת הנתונים המקוריים לאותה שנה. נתוני המקור כפופים ל־[תנאי הבנק העולמי](https://datacatalog.worldbank.org/int/public-licenses#cc-by).

בירות ומטבעות הושוו ל־UNdata מהדורת 2025 ולקודי ISO 4217, עם מקורות חדשים יותר לשינויים שאומתו. הרשימות אינן הבטחה לעדכניות עתידית. שפות הן מבחר, סמלים הם בחירה לימודית, והגייה בתעתיק עברי היא קירוב שטרם נבדק מקצועית.

## בדיקות ללא תלות ברשת

דרוש Node.js 20 ומעלה. אין צורך בהתקנת חבילות להרצת הבדיקות:

```powershell
npm test
npm run validate
npm run check:population
npm run audit
npm run build:country-index
```

הבדיקות מגינות על מבנה הנתונים, כפילויות, עקביות עם עותק המקור, קודי מטבע, תיעוד תיקונים, חיפוש, עיגול ושערי חליפין. הן אינן מוכיחות שטענה אנציקלופדית נכונה. CI מריץ את הבדיקות בכל push ובכל pull request; הוא אינו מושך או משנה נתונים חיצוניים.

## עדכון נתונים

1. למשיכת שנת אוכלוסייה שהסתיימה: `node scripts/population.cjs --fetch 2025`. כאשר עותק מקור כבר קיים, נשמר קובץ `.candidate.json` ולא נדרס העותק שנבדק. קובץ מועמד קיים לא נדרס גם הוא.
2. השוו את המועמד למקור, בדקו פערים מהותיים ותיעוד הגדרות. לאחר סקירה אפשר להחליף ידנית את עותק המקור.
3. להחלה מפורשת: `node scripts/population.cjs --apply 2025`. כל המדינות חייבות להיות זמינות לפני תחילת ההחלה.
4. במעבר לשנה חדשה יש לעדכן גם את שנת המדיניות ב־`scripts/validate.cjs`, את פקודת `check:population` ב־`package.json` ואת תיאור השנה ב־`scripts/audit.cjs` ובקובץ זה.
5. לתיקוני תוכן: עדכנו את `audit/corrections.json` עם ערך, קישור, מוציא לאור, הסבר הראיה ותאריך. הריצו `node scripts/apply-corrections.cjs` ואז את פקודות הבדיקה. אל תערכו ידנית את `data/sources.js`, הנוצר ב־`npm run audit`.

עותקי המקור נמצאים ב־`audit/sources/`. הערכים ההיסטוריים לפני הביקורת נמצאים ב־`audit/original-countries.json`; אין לעדכנם יחד עם נתוני המוצר.
